## 📝 How to Create Blog Post in Sanity

1. **Start Sanity Studio:**
```bash
cd backend_sanity
npm start
```

2. **Open Studio:**
- Go to http://localhost:3333
- Login with your credentials

3. **Create Post:**
- Click "Blog Posts" in sidebar
- Click "Create" button
- Fill in all fields:
  - Title
  - Slug (auto-generated)
  - Author
  - Published Date
  - Category
  - Excerpt
  - Main Image
  - Content (rich text)
  - SEO fields

4. **Publish:**
- Click "Publish" button
- Post is now live in Sanity

5. **Update Frontend:**
- Need to update Blog.jsx to fetch from Sanity
- I can help with this!
