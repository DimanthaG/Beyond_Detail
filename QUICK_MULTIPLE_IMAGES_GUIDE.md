# 🖼️ Quick Guide: Adding Multiple Images to Service Gallery

## How It Works

**Each Service Gallery entry = 1 image**

To add multiple images, you create **multiple entries** - one for each image.

---

## 📸 Step-by-Step: Adding Multiple Images

### For Your First Image:

1. In Sanity Studio, click **"Service Gallery"** in the left sidebar
2. Click **"+ Create"** button (top right)
3. Fill in:
   - **Service Type**: Select your service (e.g., "Auto Detail")
   - **Gallery Image**: Upload your first image
   - **Display Order**: Enter `1`
   - **Image Title** (Optional): Add a description
4. Click **"Publish"**

### For Your Second Image:

1. Click **"+ Create"** again (top right)
2. Fill in:
   - **Service Type**: Select the **same service** (e.g., "Auto Detail")
   - **Gallery Image**: Upload your **second image**
   - **Display Order**: Enter `2`
   - **Image Title** (Optional): Add a description
3. Click **"Publish"**

### For Your Third Image (and beyond):

1. Click **"+ Create"** again
2. Use the **same Service Type**
3. Upload your **next image**
4. Set **Display Order** to `3`, then `4`, then `5`, etc.
5. Click **"Publish"**

**Repeat until you've uploaded all your images!**

---

## ✅ Quick Checklist

For each image you add:
- [ ] Same **Service Type** (e.g., all "Auto Detail")
- [ ] Different **Display Order** (1, 2, 3, 4...)
- [ ] Upload a **different image**
- [ ] Click **"Publish"** (not just save)

## 💡 Pro Tips

1. **Batch Upload Strategy:**
   - Upload 3-5 images at a time
   - Take a break, then come back and add more
   - Don't try to upload 50 images at once!

2. **Display Order Matters:**
   - Order 1-5 = Your absolute best work (shows first)
   - Order 6-10 = High-quality examples
   - Order 11+ = Additional showcase images

3. **Same Service Type:**
   - All images for "Auto Detail" must use "Auto Detail" as Service Type
   - All images for "Window Tint" must use "Window Tint" as Service Type
   - Mixing service types in the same gallery won't work

4. **Publishing is Required:**
   - Draft images won't appear on your website
   - Always click **"Publish"** (green button, bottom right)
   - Published images appear within seconds

## 🔍 Verifying Your Images

After uploading, check your website:
1. Go to the service page (e.g., `/auto-detail`)
2. Scroll to the "Gallery" section
3. You should see all your images in a carousel/slider
4. Images appear in the order you set (1, 2, 3, etc.)

## ❓ Common Questions

**Q: Can I upload multiple images at once?**  
A: No, each image needs its own entry. But you can create entries quickly one after another.

**Q: What if I forget to set Display Order?**  
A: Images will still appear, but in random order. Set Display Order to control the sequence.

**Q: Can I change the order later?**  
A: Yes! Edit any entry and change the Display Order number, then republish.

**Q: How many images should I upload?**  
A: 10-15 best images per service is recommended. Quality over quantity!
