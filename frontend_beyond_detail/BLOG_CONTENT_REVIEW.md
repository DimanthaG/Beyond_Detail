## 🎯 Blog Content Recommendations

### **General Guidelines for All Blog Posts:**

#### 1. **Use Natural Keyword Placement**
When writing blog content, naturally include these phrases to trigger automatic linking:

**Service Keywords to Use:**
- "window tint" or "window tinting"
- "ceramic coating"
- "paint correction"
- "car detailing" or "auto detailing"
- "interior detailing"
- "exterior detailing"

**Location Keywords to Use:**
- "Scarborough"
- "Toronto"
- "Markham"
- "Pickering"
- "North York"

**Combined Phrases (Best for SEO):**
- "window tint in Scarborough"
- "ceramic coating in Toronto"
- "car detailing in Markham"
- "paint correction in Pickering"

#### 2. **Optimal Keyword Density**
- **3-5 service keywords** per blog post
- **2-3 location keywords** per blog post
- **1-2 combined service+location phrases** per blog post
- Don't over-optimize - keep it natural!

#### 3. **Content Structure Best Practices**
```
Introduction (100-150 words)
├─ Mention main service keyword
├─ Include location (e.g., "in Scarborough")
└─ Hook the reader

Body Sections (200-400 words each)
├─ Section 1: Problem/Question
│   └─ Use service keywords naturally
├─ Section 2: Solution/Answer
│   └─ Include location references
└─ Section 3: Benefits/Details
    └─ Mention related services

Conclusion (100-150 words)
├─ Call-to-action
├─ Reinforce main service
└─ Include location
```
